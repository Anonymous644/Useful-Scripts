# Useful Scripts

A growing collection of utility scripts for developers, automating everything from repository maintenance to security cleanups and database management.

## Scripts Included

* **[GitHub Malware Scrubber](https://www.google.com/search?q=./GitHub-Malware-Scrubber&utm_source=gemini)**: An automated PowerShell script that scans all of your GitHub repositories (owned and collaborator) for the "Contagious Interview" / "Void Dokkaebi" malware payloads and surgically eradicates them from your entire Git history.

* **[MongoDB Atlas Automated Backup & Restore](https://www.google.com/search?q=./MongoDB-Atlas-Backup&utm_source=gemini)**: A set of foolproof Windows CMD scripts to automate daily, compressed (`.gz`) backups of MongoDB Atlas databases. Features an auto-cleanup retention policy and a highly interactive, safety-first restoration menu designed to prevent accidental production data overwrites.
