# Useful Scripts

A growing collection of utility scripts for developers, automating everything from repository maintenance to security cleanups.

## Scripts Included

*   [**GitHub Malware Scrubber**](./GitHub-Malware-Scrubber): An automated PowerShell script that scans all of your GitHub repositories (owned and collaborator) for the "Contagious Interview" / "Void Dokkaebi" malware payloads and surgically eradicates them from your entire Git history.
